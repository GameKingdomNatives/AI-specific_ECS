以下是几款经典机制涌现式游戏的元规则列表，可以对照你正在构思的“无FTL星际文明”项目，看看它们在底层规则设计上有哪些共通的“语法”可以参考。

### 🧱 经典机制涌现式游戏元规则对照

#### 《矮人要塞》

| 元规则类别 | 具体规则 |
|:---|:---|
| **世界模拟** | 世界由规则驱动动态变化，地形、气候、矿产、生态圈按规则持续演化 |
| **个体代理** | 每个矮人、生物拥有独立的物理属性、历史记录与心理状态，自主决策 |
| **系统耦合** | 物理、经济、政治、社交等系统互锁运行，形成复杂网络 |
| **无预设目标** | 游戏不提供明确目标，玩家自行定义生存与叙事 |
| **低成本扩展** | ASCII符号表示世界，新增系统无需图形资产，开发成本极低 |

#### 《边缘世界》

| 元规则类别 | 具体规则 |
|:---|:---|
| **AI叙事者** | 元系统层根据财富、人数、伤亡等指标动态投放事件，控制叙事张力 |
| **间接控制** | 玩家通过下达命令和设定规则间接管理殖民者，而非直接操控 |
| **情绪驱动** | 殖民者的情绪、需求、伤病驱动行为，精神崩溃成为故事引擎 |
| **意识形态** | 扩展包引入Ideology系统，同一行为在不同意识形态下产生不同反馈 |
| **财富反馈** | 殖民地的财富增长会直接提升下一次袭击的强度，形成正反馈循环 |

#### 《塞尔达传说：旷野之息》

| 元规则类别 | 具体规则 |
|:---|:---|
| **化学引擎** | 世界由“元素”与“物质”两类对象构成，遵循三条核心规则 |
| **元素-物质** | 元素可以改变物质的状态（如火点燃树木） |
| **元素-元素** | 元素之间可以互相改变状态（如水灭火） |
| **物质-物质** | 物质之间不能互相影响状态（如树木碰撞树木无反应） |
| **逻辑自洽** | 化学引擎不追求真实物理，而是构建一套游戏内自洽的交互逻辑 |

#### 《杀戮尖塔》

| 元规则类别 | 具体规则 |
|:---|:---|
| **意图机制** | 怪物的下回合行动完全可知，玩家在确定性中做策略决策 |
| **能力牌叠加** | 能力牌的效果不断叠加、扩大，脱离计算产生难以计数的涌现效果 |
| **卡牌质变** | 单卡效果平淡，但两两组合可产生质变（积累+引爆） |
| **遗物系统** | 遗物作为装备/BUFF的重新包装，提供被动增益，与卡牌系统交叉交互 |
| **可控随机** | 保底机制：稀有卡越久未出概率越高，避免极端随机 |

#### 《洞穴探险》

| 元规则类别 | 具体规则 |
|:---|:---|
| **对象继承** | 几乎所有物体都归属某个“类别”，拥有该类别通用的行为规则 |
| **一致性效应** | 陷阱对敌人和玩家效果一致，敌人能像玩家一样拾取和使用物品 |
| **通用交互** | 玩家可以拾取并投掷几乎所有物体（道具、敌人、宝箱、NPC），创造非预期解法 |
| **简单规则叠加** | 复杂涌现来自简单透明规则的叠加，而非构建复杂AI |

#### 《Baba Is You》

| 元规则类别 | 具体规则 |
|:---|:---|
| **规则即对象** | 单词块是可移动的对象，排列成句子后成为改变游戏动态的新规则 |
| **规则语法** | 每条规则由三个基本组件构成：对象 + “Is” + 品质/效果 |
| **规则重写** | 玩家在游玩过程中不断重新配置统治游戏世界的规则 |
| **目标可变** | 胜利条件本身是可被改写的规则对象，玩家可以创造新的胜利方式 |


### 💎 对项目的对照启示（以“无FTL星际文明”为示范主题）

这些元规则列表揭示了几条共通的底层设计原则，可以直接映射到你的项目中：

1. **统一的状态空间**：《旷野之息》的“元素-物质”二分法是一个极佳范例。“无FTL宇宙”可以定义类似的基础实体（如**光速信号、亚光速飞船、行星殖民地、代际时间**），让所有机制都读写这些共享状态。

2. **简单规则的乘法关系**：《Baba Is You》的“对象+Is+品质”三元组说明了规则原子可以极简，但组合空间可以极大。将“距离-时间-通讯”三元关系组织起来可以成为类似的核心规则语法。

3. **元规则层的存在**：《边缘世界》的AI叙事者和《矮人要塞》的世界模拟，都是在底层规则之上叠加的“调控层”。“无FTL”主题天然需要一个**时间延迟模拟器**作为元规则层，来调度跨越世纪的事件。

4. **低成本扩展路径**：《矮人要塞》用ASCII符号实现无限系统扩展，这与各类低美术预算路径如“矢量艺术+文字驱动”等路径高度一致。在项目中，可以用**矢量图形表示星系/航线/舰船**，用**文本表示事件与交互**，保持美术成本极低的同时，将开发精力集中在机制耦合上。
