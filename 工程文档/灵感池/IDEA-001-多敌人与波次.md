# IDEA-001 · 多敌人与波次

- 级别：P1
- 状态：已落地（iter-004，待人实跑判定）
- 提出：2026-10-26（人，第二轮验收 Q7）

## 想法

现在只有 1 架敌机，人反馈「一个敌人太少、太单调，还想继续打更多敌人」。可选方向：一次 2–3 架、或击杀后补位的连续波次，并在波次间给短喘息。

## 对齐检查

- [x] 服务核心循环（3 分钟对射的压迫感与节奏）
- [x] 强化感觉词「压迫 / 精算」（更多目标 = 更多辐能取舍）
- [ ] 不与设计支柱冲突（需确认「纯色块 + 不调数值」前提下，多敌是否只做数量变化）
- [x] 不违反边界约束（不动引擎包体）

## 验证方式

场景里把敌人数量作为可配参数：先加第 2 架同型敌机，打 2 轮各 5 分钟，看「压迫感」是否上升、辐能是否变成瓶颈；再加「击杀后 3 秒补位」的波次，比较两者的节奏差异。

## 人的裁定

**采纳**（2026-10-26）：同屏 2 架、交战节流 + **轮换压制**（一方开火压制、一方排散找位，打不动了换手，形成循环）、补位 3 波；并要求「开火产辐 > 辐散」，玩家机同规则。落地见 [iter-004](../迭代记录/迭代-004-多敌与波次.md)。
