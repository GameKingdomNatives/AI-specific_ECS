# 工程文档（顶层工程文件目录）

> 这是**工程事实的顶层入口**：项目身份、边界、状态、迭代、灵感、系统维护、变更、校正、交接。
> 操作流程在 `docs/workflow/`；代码契约在 `contracts/` 与 `docs/systems/`。

## 目录

| 目录 / 文件 | 管什么 | 单一事实来源 |
|---|---|---|
| [项目身份/项目身份.md](项目身份/项目身份.md) | 项目是谁：定位、支柱、感觉词、非目标 | 本文件（方向） |
| [当前状态.md](当前状态.md) | 一屏状态摘要 + 交接入口 | 摘要；详细事实在 `docs/handoff.md` |
| [边界约束.md](边界约束.md) | 10 条边界、HARD 清单、保护路径 | `AGENTS.md`（可执行）；本文件解释 why |
| [迭代记录/](迭代记录/) | 每次迭代的事实记录与索引 | 本目录 |
| [验收记录/](验收记录/) | 人的验收结论（L4）与固定问题表 | 本目录 |
| [灵感池/](灵感池/) | 未采纳的想法（IDEA-NNN） | 本目录 |
| [系统维护/](系统维护/) | 文档/记忆规范、扩展指南、维护入口 | 本目录 + `docs/runbooks` |
| [变更记录/](变更记录/) | 按月归档的变更与证据 | 本目录 |
| [校正记录/](校正记录/) | 方向校正 / 回顾 / 一次性复盘 | 本目录 |
| [交接/交接清单.md](交接/交接清单.md) | 新会话首读顺序与待办 | 入口；详细日志在 `docs/handoff.md` |
| [_模板/](_模板/) | 迭代 / 开工 / 收尾 / 方向校正模板 | 本目录 |

## 单一事实规则（不得制造平行真相）

- **方向**：`项目身份/项目身份.md`。
- **可执行边界**：`AGENTS.md`（本目录的边界约束只解释 why，冲突以 AGENTS 为准）。
- **详细状态与交接**：`docs/handoff.md`（本目录的 `当前状态.md` 只放一屏摘要）。
- **流程**：`docs/workflow/`。
- **代码契约**：`contracts/`、`docs/systems/`。
- **决策理由**：`docs/adr/`。

## 更新时机

| 发生了什么 | 改哪里 |
|---|---|
| 方向/支柱/感觉词变化 | 项目身份（同时补校正记录） |
| 一轮迭代结束 | 迭代记录 + 当前状态 + 变更记录 |
| 需要人判定手感/方向 | 验收记录填表；通过后改迭代状态 |
| 新想法 | 灵感池新建 IDEA，不自行采纳 |
| 新边界 / 权限变化 | AGENTS.md + 边界约束 |
| 会话交接 | 交接清单 + docs/handoff.md |
