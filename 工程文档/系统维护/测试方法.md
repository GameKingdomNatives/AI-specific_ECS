## 2. 游戏侧契约测试（6 个文件）

```bash
# 先编译，再逐个跑（沙箱里不要用 node --test 目录，会 EPERM）
node node_modules/typescript/bin/tsc -b
node apps/game/dist-ts/tests/flux.contract.test.js
node apps/game/dist-ts/tests/controls.contract.test.js
node apps/game/dist-ts/tests/weapon.contract.test.js
node apps/game/dist-ts/tests/enemy.contract.test.js
node apps/game/dist-ts/tests/projectile.contract.test.js
node apps/game/dist-ts/tests/combat.contract.test.js
```

覆盖：辐能状态机边界、WASD/护盾/排散/过载拒绝、三槽发射与 effect、敌机两态与开火条件、弹丸出界回收、护盾转硬辐能与击杀。

## 3. 全量门禁怎么读

```bash
node tools/gate.mjs            # 权威；产出 artifacts/gate/<run>/report.md|json
node tools/gate.mjs --fast     # 跳过 depcruise/drill，其余相同
```

- 只看「退出码 0」不够；警告=失败（eslint warnings>0 也红）。
- 解析型检查（depcruise/findings/registry）必须解析结果本身。
- 报告有环境指纹（node/平台/pipes）；pipes=blocked 时 build/storybook/starter 属 L3，**不计 PASS**。
- 失败先看对应 `<step>.log`，不要猜。

## 4. 深检与夜检

```bash
node tools/deep-audit.mjs --dry-run   # 只出摘要，不写 stamp
node tools/deep-audit.mjs             # 全量门禁 + 摘要，写 .gate/deep-stamp.json
node tools/nightly.mjs --dry-run      # 夜检摘要（凌晨日期用 Asia/Shanghai）
```

`flow ship` 会在距上次深检 ≥5 提交时自动跑深检。
