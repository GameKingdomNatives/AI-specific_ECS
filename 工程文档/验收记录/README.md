# 验收记录

> 机器能证明的进「测试方法」（`../系统维护/测试方法.md`）；只有人能给的结论进这里。
> 对照：迭代记录负责"做了什么"，验收记录负责"人判定是否成立"。

## 命名

`验收-<迭代号>-<主题>.md`，例如 `验收-001-002-首轮.md`。

## 规则

- 一次验收至少 3 轮、每轮 10 分钟；同一版本、同一操作方式。
- 只记录人的观察与判断，不抄机器读数（读数放测试方法/门禁报告）。
- 结论只允许：**通过 / 需重做 / 中止**，并写一句下一步。
- 通过后，迭代记录状态改为「已完成」；需重做则写清哪一条不达标。
