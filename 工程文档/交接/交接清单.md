# 交接清单

> 新会话首读顺序；详细状态与待办以 `docs/交接.md` 为准（本文件不重复正文）。

## 首读顺序

1. `工程文档/当前状态.md`（一屏）
2. `docs/交接.md` 顶部（详细事实、待人裁定、环境）
3. `工程文档/项目身份/项目身份.md`（方向）
4. `docs/workflow/迭代流程.md`（本轮流程）
5. `工程文档/迭代记录/` 最后一个记录（上一轮停在哪）

## 常用命令

```bash
node tools/status.mjs
node tools/gate.mjs [--fast]
node tools/flow.mjs status|policy|sweep|ship
node tools/push.mjs [--go]
```

## 会话级注意事项

- 受限会话（禁管道子进程）下 build/storybook/starter 是 L3，不计 PASS。
- 推送前先看通道结论；分支由 `flow` 管理。
- 任何"完成"都必须有门禁报告或明确的 L3 说明。
