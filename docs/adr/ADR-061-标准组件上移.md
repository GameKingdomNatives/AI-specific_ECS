# ADR-061：标准变换/尺寸组件上移到引擎 data 层

- 日期：2026-10-27
- 状态：已采纳
- 变更级别：SOFT（新增引擎数据导出）+ 受保护路径改动（`tools/test-baseline.json`，已用 `ALLOW_PROTECTED=1` 过门禁）

## 背景

F-01（来源 `docs/game/引擎反馈.md`）：游戏为了复用渲染插值、物理桥与回放，只能从 `@itb/fixture` import `Position` / `Velocity` / `Box`。夹具是**测试替身**，产品依赖测试替身，方向反了；而且两边各自 `defineComponent` 会得到同名但不同对象的组件定义，场景注册表与系统一旦引用不同实例，列式存储就可能对不上。

## 决定

1. 引擎新增 `packages/engine/src/data/components.ts`，定义 `Position`（f64 x/y）、`Velocity`（f64 x/y）、`Box`（f32 size、u32 tint）。
2. 由既有子路径 `agent-specific_ecs/data` 导出（`data/index.ts`）。
   - **不改 `packages/engine/package.json`**：`./data` 子路径已存在，避免动保护路径、不必新增 HARD 审批。
3. 夹具改为**转出引擎的同一份对象**：`packages/fixture/src/index.ts` 里 `import` 后 `export`，不再自己定义。`Bullet` 属于演示内容，留在夹具。
4. 游戏侧（`apps/game/src` 与 `apps/game/tests`）的 `Position` / `Velocity` / `Box` 引用全部改到 `agent-specific_ecs/data`；夹具只保留 `Bullet` 与演示系统（`spawnBoxes` / `createBoxSpawnerSystem` 等）。
5. 测试基线 `tools/test-baseline.json` 从 45 提到 47：本轮新增两个测试文件，而基线语义是「测试文件只许增不许减」；同时修好 drill 的「移走契约测试」拦截（隐藏一个后 46 < 47，重新命中「少于基线」）。

## 后果

- 游戏与引擎共用一份标准组件定义；夹具降级为「转出 + 演示内容」。
- `api-surface` 快照无需改动（快照只覆盖 index/core/ports/scene/bridge 的公共声明，`data` 不在其中）。
- 引擎包体新增一个纯数据模块，不含游戏内容（`package-surface` 通过）。
- 以后新增标准词汇（如 `Rotation` / `Scale`）走同一位置；游戏不得再向夹具要标准组件。
