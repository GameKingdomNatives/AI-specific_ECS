# 系统 · game.waves 波次推进

## 职责
清场后补下一波敌机，最多 3 波；把「还有没有敌人、第几波、补位倒计时」写回 `Run`，供 HUD 与事件流读取。

## 阶段
`cleanup`（在伤害结算与实体回收之后，避免同一 tick 刚死就补位）。

## 读 / 写
- 读：`Run`（玩家）、`Mecha`（判断场上是否还有敌机）
- 写：`Run`；生成敌机走 `CommandBuffer`（阶段末统一 flush）

## 不变量
- 同一时刻最多一个补位倒计时；倒计时期间不重复启动。
- 超过 `maxWave` 后不再补位，清场即结束。
- 补位点按波次固定（左/右交替），保证同输入重跑哈希一致。

## 所有权
`owns: ['waves']` —— 只有本系统写 `Run` 与生成敌机。

## 验证
`apps/game/tests/waves.contract.test.ts`：清场才倒计时、180 tick 后补 2 架、超波数停住、补位点固定可回放。
