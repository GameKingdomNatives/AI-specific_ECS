# game.enemyAi · 敌机决策

- 阶段：ai
- 系统名：`game.enemyAi`
- 文件：`apps/game/src/game/systems/enemy.ts`

## 职责

多机时轮换压制：同一 tick 只有一架攻击态，攻击者辐能到换手线（60）就让位给已排散干净的同伴（≤30），自己退到侧后方排散，形成「压制 → 排散 → 接管」的循环。只读位置/辐能与交战令牌，不读玩家输入。
只看得到位置与辐能，不看玩家输入：辐能越过阈值就关盾排散并后撤，否则压入射程带、朝玩家瞄准。

## 输入 / 输出
- 读：`Position`、`Flux`、`Mecha`、`Ai`
- 写：`Position`、`Aim`、`Shield`、`Vent`、`Ai`

## 不变量
- 同一 tick 最多一架敌机被选中为攻击者（`selectAttacker` 纯函数），其余写 `Vent.active=true`。
- 单机时退化为旧行为：辐能到换手线就自己排散后撤。
- 排散态侧向机动并拉开到射程 1.4 倍，避免贴脸。
- 令牌只依赖世界状态（辐能、模式、id），无随机，可回放。

- 被电子压制（`Suppressed.ticks > 0`）时不开盾，即使辐能很低。
- 决策不含随机数：同一世界状态得到同一行为，回放可复现。
- 排散与开盾互斥；过载时同样停排散。
- 后撤方向是玩家反方向，速度降为 80%。
