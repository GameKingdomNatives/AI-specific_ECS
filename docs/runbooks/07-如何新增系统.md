# 如何新增一个系统（可照做）

1. **定义数据**：在 `packages/engine/src/demo/` 或对应模块声明组件（`ComponentDef`）；需要编辑器表单则在 `packages/engine/src/scene/meta.ts` 的 `ComponentMeta` 与 `apps/game/src/editor/component-meta.ts` 登记字段。
2. **写工厂**：`createXxxSystem(deps) => SystemDef`，声明 `name/phase/reads/writes/update`；结构变更只能进 `ctx.commands`，跨系统通信走事件总线。
3. **注册**：在 `apps/game/src/system-registry.ts` 的 `createSystems` 加入；需要参数则从 `params[id]` 读取，并在 `apps/game/src/editor/system-meta.ts` 增加 `SystemMeta`。
4. **场景条目**：在 `apps/game/scenes/*.scene.json` 的 `systems` 加 `{id, phase, enabled, after, params}`；`pickSystems` 会按场景重排。
5. **测试**：至少一条契约测试 `packages/engine/tests/<system>.contract.test.ts`；涉及 schema/参数/预算的改动补对应单测。
6. **系统卡**：在 `docs/systems/` 新增一页（职责/输入/输出/不变量/所有权/验证）。
7. **门禁**：`node tools/gate.mjs --fast` 通过后跑全量 `node tools/gate.mjs`；提交信息含动机/改动/证据。
8. **UI（可选）**：需要可视化检查器时，使用元数据表单；需要 Storybook 时在 `apps/game/src/editor/editor.stories.tsx` 加纯展示 story。

禁止：系统间直接调用、核心层 import 实现、热路径走事件总线、用 `any`/断言绕过契约、在系统内直接增删实体/组件。
