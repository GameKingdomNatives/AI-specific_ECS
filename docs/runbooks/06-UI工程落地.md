# 06 · UI 工程独立落地方案

目标：把 UI（React 覆盖层 + Tailwind + Storybook）作为**可独立交付的工程单元**，设计方与开发方各自零摩擦上手；不依赖 Onlook、不依赖 Docker。

## 1. 资源清单

| 资源 | 路径 | 面向 |
|---|---|---|
| UI 模块源码 | `apps/game/src/ui/` | 开发 |
| UI 模块说明 | `apps/game/src/ui/README.md` | 开发 |
| 最终 UI 方案 | `docs/ui-final-plan.md` | 双方 |
| 设计师上手 | `docs/runbooks/05-设计师上手.md` | 设计 |
| 本文档 | `docs/runbooks/06-UI工程落地.md` | 开发/合作方 |
| 静态 Storybook 产物 | `artifacts/storybook-static/`（构建生成） | 设计（浏览器打开） |
| 静态服务器 | `tools/serve-static.mjs` | 开发 |

## 2. 环境矩阵

| 角色 | 需要安装 | 不需要 |
|---|---|---|
| 设计方 | 浏览器 | Node、Docker、数据库、付费席位 |
| 开发 | Node ≥ 22、npm；仓库根 `npm install` | Docker、Supabase |
| CI / 门禁 | 同上 | 外部服务 |

## 3. 安装与运行（开发）

```powershell
# 仓库根
npm install
npm run storybook          # 开发模式 http://localhost:6006
npm run storybook:build    # 静态包 → artifacts/storybook-static
npm run storybook:serve    # 静态包 http://localhost:7007
node tools/gate.mjs        # 全量门禁（含 storybook 构建）
```

只跑 UI 时不需要 `npm run dev`（游戏主循环），Storybook 会单独渲染 `App` 组件。

## 4. 交付给设计方

1. 构建：`npm run storybook:build`
2. 打包（可选）：
   ```powershell
   Compress-Archive -Path artifacts\storybook-static\* -DestinationPath artifacts\ui-kit-storybook.zip -Force
   ```
3. 交付：zip 或内网静态地址；设计方解压后双击 `index.html` 可能受浏览器模块加载限制，
   推荐用 `npm run storybook:serve` 起本地服务（或任意静态服务器）后访问 `http://localhost:7007`。
4. 设计方按 `docs/runbooks/05-设计师上手.md` 对照、提差异。

## 5. 新增/修改组件流程

1. 改 `src/ui/*.tsx`（props 只接受纯数据/回调）；
2. 补 `*.stories.tsx`（默认 / 禁用 / 错误 至少三态）；
3. 若新增 token，先改 `docs/ui-final-plan.md` §5；
4. `node tools/gate.mjs` 通过后提交；
5. 重新构建静态包给设计方。

## 6. 本地设计评审闭环（M3，零成本）

不使用任何云端设计服务；设计方用任意工具出稿/标注，Storybook 作唯一验收面。

1. 开发构建静态包：`npm run storybook:build`；需要时 `Compress-Archive` 成 zip。
2. 设计方打开静态包（`npm run storybook:serve` → `http://localhost:7007`），对照两个入口：
   - `战斗 HUD / 控制条`：就绪 / 有诊断 / 存档失败；
   - `设计 token / 总览`：颜色、字号、间距、圆角的真实值。
3. 设计方按「组件名 + 状态 + 期望值」提差异（模板见 runbook 05）。
4. 开发改 `src/ui/**` 与 `*.stories.tsx`，重新构建静态包。
5. 差异走 `node tools/gate.mjs` 后提交。

约定：

- token 唯一事实源是 `apps/game/src/ui/tokens.ts`，新增 token 必须先改它和 `docs/ui-final-plan.md`；
- 不引入 Figma Dev Mode / MCP / 付费席位（用户已明确：云端、收费、产物不可直接用）；
- Figma 免费版仅作可选草稿工具，不是评审依赖。

## 7. 排错

| 现象 | 处理 |
|---|---|
| `storybook` 起不来 | 确认 `storybook` 与 `@storybook/react-vite` 均为 10.6.x；Vite 8 在 peer 范围内 |
| 改 `vite.config.ts` 后样式没变 | 重启 dev server |
| 静态包打开白屏 | 用 `npm run storybook:serve`（不要 `file://` 直开） |
| 门禁报 `ui-no-engine-internals` | UI 里 import 了引擎/控制器，改为经 props 传入 |
