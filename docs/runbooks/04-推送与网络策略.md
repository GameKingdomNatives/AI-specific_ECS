# 04 · 推送与网络策略

> 症状：`Connection reset by 20.205.243.160 port 443` / `Could not read from remote repository`。
> 先分清两件事：**分支保护放行了吗**（stamp）与**网络通道通不通**（22 / 443）。两者失败的样子都像"推不上去"，处理完全不同。

## 1. 判定顺序

```bash
node tools/push.mjs          # 体检：HEAD、工作区、stamp、ssh 配置、22/443 通道
node tools/push.mjs --go     # 条件满足才推：干净 + stamp
```

- **stamp 缺失** → 不是网络问题，回去跑 `node tools/gate.mjs`。
- **工作区有未提交** → 先提交（门禁失败不许提交的规则仍适用）。
- **stamp 有、通道不通** → 纯网络问题，按下节换通道。

## 2. 通道选择

### A. 22 端口可用（优先）

```bash
# 若 ~/.ssh/config 把 github.com 改写到 443，临时绕过：
git -c core.sshCommand="ssh -F NUL -p 22 -o StrictHostKeyChecking=accept-new" push --follow-tags origin main

# 或永久加一个别名，互不影响：
# ~/.ssh/config
# Host github-22
#   HostName github.com
#   Port 22
#   User git
#   IdentityFile ~/.ssh/id_ed25519
git remote set-url origin git@github-22:GameKingdomNatives/AI-specific_ECS.git   # 注意替换为真实组织名
```

### B. 只有 443 可用

```bash
git remote set-url origin ssh://git@ssh.github.com:443/GameKingdomNatives/AI-specific_ECS.git
git push --follow-tags origin main
```

443 上的 SSH 在国内网络经常被重置（就是这次的报错）。**重置不等于配置错**：换网络（手机热点/VPN/代理）后同一命令即可通过。

### C. SSH 全不通：HTTPS + PAT

```bash
git remote set-url origin https://github.com/GameKingdomNatives/AI-specific_ECS.git
# 用 Git Credential Manager 登录，或提供 fine-grained PAT（contents: write）
git push --follow-tags origin main
```

### D. 完全离线：bundle 搬运

```bash
git bundle create itb-$(git rev-parse --short HEAD).bundle --all
# 把 bundle 复制到能上网的机器：
git clone itb-xxxx.bundle itb-relay && cd itb-relay
git remote set-url origin git@github.com:GameKingdomNatives/AI-specific_ECS.git
git push --follow-tags origin main
```

## 3. 诊断读数怎么读

| 输出 | 含义 | 动作 |
|---|---|---|
| `github.com:22 通` | SSH 主通道可用 | 用 A |
| `ssh.github.com:443 通` 但 reset | TCP 可达但握手被重置 | 换网络/代理，或用 22 |
| 两个都不通 | 出口被挡 | 代理/VPN 或 D |
| `stamp 缺失` | 策略未放行 | 跑门禁，不要 `--no-verify` |
| `ssh 配置 github.com → ssh.github.com:443` | `~/.ssh/config` 在改写 | 想走 22 就按 A 绕过 |

## 4. 原则

- **失败不改策略**：推送失败不是放宽门禁、不是 `--no-verify` 的理由。
- **失败要留原文**：把报错原文（IP、端口、退出码）记进 handoff，下一次先看通道。
- **通道是环境事实**：写进交接，不靠记忆。
