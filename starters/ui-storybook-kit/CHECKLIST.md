# 新 UI 项目起步检查单

复制这份 starter 后，按顺序勾完再开始写业务。

## 环境

- [ ] Node ≥ 22
- [ ] `npm install` 成功
- [ ] `npm run storybook` 能打开 `:6006`
- [ ] 不需要 Docker / 数据库 / 付费账号

## 组件规范

- [ ] 组件在 `src/components/`，一个文件一个组件
- [ ] 只接受 props（纯展示），不 import 业务、引擎、网络代码
- [ ] 每个组件至少三个 story：默认、禁用、空/错误
- [ ] 组件内不写魔法颜色/字号；一律来自 `tokens.ts` 或 Tailwind 类
- [ ] 空数组/空字符串有明确空状态

## 状态矩阵

- [ ] 列出组件 × 状态矩阵（默认/hover/focus/disabled/空/错误/长文案）
- [ ] 设计稿没画的状态已补
- [ ] 长文案有截断或换行策略

## 交付

- [ ] `npm run build` 成功
- [ ] `npm run serve` 可打开静态包
- [ ] 静态包 zip 能发给非开发人员打开
- [ ] 设计方已对照真实渲染确认

## 工程

- [ ] `storybook build` 已进 CI/门禁
- [ ] story 与组件同目录、同命名
- [ ] 新增依赖前确认许可证（优先 MIT）
- [ ] 不引入云服务或付费席位作为评审前提
