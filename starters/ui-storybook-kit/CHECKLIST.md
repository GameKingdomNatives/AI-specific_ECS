# 新项目起步检查单

复制这个套件后，按顺序勾完再开始写业务。

## 环境

- [ ] Node ≥ 22（`node -v`）
- [ ] `npm install` 成功
- [ ] `npm run storybook` 能打开页面
- [ ] 不需要 Docker、数据库、付费账号

## 组件规范

- [ ] 组件放 `src/components/`，一个文件一个组件
- [ ] 组件只接收参数，不引用业务、网络、引擎代码
- [ ] 每个组件至少三个 story：默认、边界（空/错）、禁用
- [ ] 组件内不写死颜色与字号；来自 `tokens.ts` 或 Tailwind 类
- [ ] 空数组/空字符串有明确的空状态文案

## 状态清单

- [ ] 已列出「组件 × 状态」表格
- [ ] 设计稿没画的状态已补
- [ ] 长文案有截断或换行策略

## 交付

- [ ] `npm run build` 成功
- [ ] `npm run serve` 能打开静态包
- [ ] 静态包压缩后能发给不装任何工具的人
- [ ] 有一次对照真实渲染的确认

## 工程

- [ ] `storybook build` 已进持续集成
- [ ] story 与组件同目录、同名前缀
- [ ] 新增依赖前确认许可证（优先 MIT）
- [ ] 不引入云服务或付费席位作为评审前提
